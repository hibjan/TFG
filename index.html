Aplicación para la navegación en colecciones de contenidos multimedia

Juan Andrés Hibjan Cardona · Leonardo Prado de Souza

⚙️

Stack Tecnológico

Backend Java 17 con Jakarta Servlets sobre Apache Tomcat 10. Frontend en Vanilla JavaScript con Vite. Base de datos PostgreSQL 16.

📁

Estructura del Proyecto

Arquitectura modular: backend/ (MVC con controller, dao, service, model), frontend/ (componentes JS), database/ (esquema SQL), scripts/ (pipelines de datos).

🎬

Datasets Utilizados

Validado con dos datasets reales: TMDb (películas, actores, géneros) y DBLP (publicaciones académicas y autores). Scripts de extracción en Python y Go.

🐳

Despliegue

Entorno completamente containerizado con Docker Compose. Producción con 4 servicios: PostgreSQL, Tomcat, Nginx y túnel seguro Cloudflare. Se despliega con un solo comando explicado en el README.
