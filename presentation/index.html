ContextContexto

Information overload outgrew our toolsLa sobrecarga de información superó a nuestras herramientas

Direct search is rigid, classic filters are opaque, recommenders erase yourLa búsqueda directa es rígida, los filtros clásicos son opacos, los recomendadores anulan tu agency. The three richer mechanisms that do help —agencia. Los tres mecanismos más ricos que sí ayudan — faceted filtering, navigation between related collectionsfiltrado facetado, navegación entre colecciones vinculadas and set operations — exist only in isolation.y operaciones de conjuntos — solo existen de forma aislada.

  • 1. Modelo formal (unifica filtrado + navegación + unión)
  • 2. Motor + API REST
  • 3. Validar en 2 catálogos + usuarios
Our goalNuestro objetivo

A domain-agnostic exploration engineUn motor de exploración agnóstico al dominio

  • Define a formal navigation model that unifies filtering, transversal navigation, and union.Definir un modelo de navegación formal que unifique el filtrado, la navegación transversal y la unión.
  • Implement the model into a single exploration engine exposed via a RESTful API.Implementar el modelo en un único motor de exploración expuesto mediante una API RESTful.
  • Validate the engine conceptually and with users on two structurally different catalogs.Validar el motor conceptualmente y con usuarios sobre dos catálogos estructuralmente distintos.
  • Fase 1: CLI Java · TMDB → modelo formal
  • Fase 2: API REST + web · DBLP · validación
